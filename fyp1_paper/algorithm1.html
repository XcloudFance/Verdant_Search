Algorithm 1: Hybrid Retrieval with RRF Fusion

Two-stage retrieval combining BM25 keyword search with HNSW vector search

⏱️ Time Complexity

BM25 Search: O(|q| × log N) where |q| = query length, N = document count

HNSW Search: O(d × log N) where d = embedding dimension (768)

RRF Fusion: O(K₁ + K₂) typically K₁ = K₂ = 100

Overall: O(log N) due to parallel execution

💾 Space Complexity

Inverted Index: O(V × N) where V = vocabulary size

HNSW Index: O(N × d) stored in memory for fast access

Overall: O(N × d) dominated by vector index
