# LaTeX Beamer 编译说明

## 环境部署

### 1. 安装 TeX Live（必需）

在 Manjaro Linux 上安装完整的 LaTeX 环境：

```bash
sudo pacman -S texlive-core texlive-bin texlive-latexextra texlive-fontsextra texlive-bibtexextra texlive-pictures
```

### 2. 验证安装

```bash
pdflatex --version
bibtex --version
```

如果显示版本信息，说明安装成功。

---

## 编译方法

### 方法一：使用自动编译脚本（推荐）

```bash
# 在项目目录下执行
./compile.sh
```

这个脚本会自动执行完整的编译流程，包括：
1. 第一次 pdflatex 编译（生成辅助文件）
2. bibtex 处理参考文献
3. 第二次 pdflatex 编译（更新引用）
4. 第三次 pdflatex 编译（确保所有引用正确）

### 方法二：手动编译命令

```bash
# 进入项目目录
cd /home/lancelot/下载/FYP_SLIDE

# 第一次编译
pdflatex -interaction=nonstopmode sample.tex

# 处理参考文献
bibtex sample

# 第二次编译
pdflatex -interaction=nonstopmode sample.tex

# 第三次编译
pdflatex -interaction=nonstopmode sample.tex
```

### 方法三：使用 latexmk（一键编译）

如果安装了 latexmk（通常包含在 texlive-core 中）：

```bash
latexmk -pdf -interaction=nonstopmode sample.tex
```

---

## 清理辅助文件

编译后会生成很多辅助文件（.aux, .log, .out 等），可以使用清理脚本：

```bash
./clean.sh
```

或手动清理：

```bash
rm -f *.aux *.log *.out *.toc *.nav *.snm *.vrb *.bbl *.blg *.bcf *.run.xml
```

## 常见问题

### 1. 编译报错：找不到某个包

```bash
# 尝试安装额外的 LaTeX 包
sudo pacman -S texlive-publishers texlive-science
```

### 2. 参考文献不显示

确保执行了完整的编译流程（pdflatex → bibtex → pdflatex × 2）

### 3. 中文支持问题

当前文档主要是英文内容。如需中文支持，可能需要安装：

```bash
sudo pacman -S texlive-langchinese
```

### 4. 图片无法显示

确保所有 PDF 和 PNG 图片文件都在项目目录中，并且文件名与 LaTeX 源码中的引用一致。

## 快速开始

```bash
# 1. 安装 LaTeX 环境（首次使用）
sudo pacman -S texlive-core texlive-bin texlive-latexextra texlive-fontsextra texlive-bibtexextra texlive-pictures

# 2. 编译文档
./compile.sh

# 3. 查看生成的 PDF
xdg-open sample.pdf
```

## 高级编译选项

### 只编译一次（快速预览，不处理引用）

```bash
pdflatex sample.tex
```

### 开启详细错误信息

```bash
pdflatex -file-line-error -halt-on-error sample.tex
```

### 使用 XeLaTeX（如果需要更好的字体支持）

```bash
xelatex sample.tex
bibtex sample
xelatex sample.tex
xelatex sample.tex
```
